# Signal study: credit conditions and equity returns

Does the credit-conditions index (CCI) from the monthly lender survey help predict the return on the equity index?
The study is pre-registered: the analysis was fixed and signed off before it was run.

| Path | What it holds |
|---|---|
| `registration/PREREG-2026-07.md` | the registration (study CCI-EQ-01), signed off in July 2026 |
| `data/dev/` | the development sample, January 2004 to December 2023: `signal.csv` (the index at each month-end) and `returns.csv` (each month's return) |
| `results/RESULTS.md` | the results template the research committee reads |
| `notes/` | working notes from the team |

The registration, the data and the notes are inputs to the study: they are kept as they are.
